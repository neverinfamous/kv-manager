# Cloudflare KV Manager v2.3.3

## Highlights

- **Strict Origin & CSRF Protection**: Credentialed CORS headers now honor an explicit `ALLOWED_ORIGINS` allowlist, blocking untrusted cross-origin state changes.
- **Locked-Down Auth & Worker Subdomains**: Local mock authentication requires zero production secrets, while default `workers.dev` and preview URLs stay disabled.
- **Zero-CVE Runtime Container**: Alpine `musl` upgrades and fresh `glob`, `minimatch`, and `brace-expansion` patches secure the Docker image.

## Changed

- **config**: Disable `workers_dev` and `preview_urls` by default in Wrangler configurations to prevent unprotected Worker routes.
- **deps**: Refresh `jose`, `wrangler`, `vite`, `eslint`, and `@cloudflare/workers-types` to their latest releases.
- **ci**: Upgrade SHA-pinned GitHub Actions to `actions/checkout` v7, `actions/setup-node` v7, and `gitleaks-action` v3.

## Security

- **cors**: Enforce `ALLOWED_ORIGINS` allowlisting and reject untrusted cross-origin state-changing API calls with `403 Forbidden` (`GHSA-j3r9-4pwc-c8mh`).
- **auth**: Restrict `localhost` JWT bypass strictly to unauthenticated mock mode without production or Access secrets (`GHSA-x3mg-rm2g-357p`, `GHSA-p483-22hw-9vjv`).
- **docker**: Upgrade Alpine `musl` (`CVE-2026-107891`) and patch bundled `glob`, `minimatch`, `brace-expansion`, and `ip-address` dependencies.

## Install

```bash
docker pull writenotenow/kv-manager:v2.3.3
```

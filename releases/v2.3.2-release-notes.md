# Cloudflare KV Manager v2.3.2

## Highlights

- **Security Patch Release**: All known dependency vulnerabilities are resolved, including 18 `undici` advisories. You get a safer local toolchain and Docker image.
- **Hardened Container**: The image drops from 18 known vulnerabilities to a single unrated `musl` finding that awaits an upstream Alpine fix.
- **Fresh Stack**: React 19.3, Vite 8.3, Wrangler 4.156, and the latest Radix UI components.

## Changed

- **deps**: Updated all runtime and development dependencies, and refreshed overrides for `undici`, `tar`, `minimatch`, `picomatch`, and `flatted`.
- **ci**: Pinned every GitHub Action to a commit SHA and every runner to `ubuntu-24.04` for reproducible builds.
- **ci**: Updated GitHub Actions to Node 24 releases to resolve deprecation warnings.

## Security

- **deps**: Raised `undici` to 7.30.1, clearing all open Dependabot alerts for the project.
- **docker**: Patched bundled `undici` and `ip-address`, and upgraded OpenSSL, zlib, and musl in the runtime image.

## Install

```bash
docker pull writenotenow/kv-manager:v2.3.2
```

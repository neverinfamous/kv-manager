# Cloudflare KV Manager v2.3.1

## Highlights

- **Enhanced Accessibility**: The Webhook Manager has been fully audited and updated to ensure perfect screen reader compatibility, eliminating broken associations.
- **Dependency & Build Maintenance**: Core dependencies have been updated and Vite 8 legacy build warnings have been suppressed for a cleaner, more secure build pipeline.

## Changed

- **build**: Suppress legacy `configLoader` warnings in Vite 8 to provide cleaner build logs and smoother developer experience.

## Fixed

- **a11y**: Nest form inputs directly inside their corresponding labels in the Webhook Manager, resolving screen reader association warnings.
- **a11y**: Replace an invalid events label with a styled division to eliminate lingering accessibility complaints without sacrificing visual design.

## Security

- **deps**: Update project dependencies, resolve overrides, and sync `esbuild` to the latest version for enhanced stability and safety.

## Install

```bash
docker pull writenotenow/kv-manager:v2.3.1
```

# Cloudflare KV Manager v2.3.0

## Highlights

- **Scheduled Threshold Monitoring**: Automatically track KV metric thresholds on a schedule to ensure consistent performance monitoring.
- **Automated Health Penalties**: Integrate active threshold breaches directly with the health scoring system and audit logs to improve visibility and accountability.

## Added

- **monitoring**: Add scheduled threshold monitoring for KV metrics (#140). This allows you to proactively track and alert on key performance indicators.
- **monitoring**: Implement documented health penalty deductions and audit log integration for active threshold breaches, ensuring your health scores accurately reflect current system state.

## Changed

- **main**: Synchronize docs and configuration to align with the newly introduced scheduled threshold monitoring system.

## Fixed

- **monitoring**: Prevent orphaned threshold states from penalizing your overall health score, ensuring accurate metrics.
- **api**: Correct namespace JOIN column names in both threshold listing and mutations to resolve data retrieval errors.
- **api**: Bypass rigid 404 namespace validation on threshold creation by automatically upserting missing UI selections.
- **ui**: Unwrap JSON responses correctly in the threshold service to restore UI stability and data rendering.
- **config**: Resolve CRLF invisible character corruption in the `wrangler.toml` triggers block, preventing unexpected deployment failures.
- **deps**: Update dependencies and security patches for enhanced stability and safety.

docker pull writenotenow/kv-manager:v2.3.0

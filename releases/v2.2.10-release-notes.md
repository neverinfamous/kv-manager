# Cloudflare KV Manager v2.2.10

- **Pnpm v11 Workspaces**: We have migrated the entire project to `pnpm` workspaces for faster, deterministic installations and improved dependency resolution across modules.
- **Robust CI/CD Pipelines**: Migrated our GitHub Actions workflows to `pnpm` and enforced stricter safety gates, ensuring high standards for code quality and security on every push.
